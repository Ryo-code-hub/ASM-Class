# 作业四 思路说明：乘法指令和过程调用

## 一、题目要求

输出九九乘法表。基本要求为至少实现一个过程调用并能正确调用与返回（`CALL` 与 `RET` 指令）；第 1) 小问进一步要求过程中的确用到主过程正在使用的寄存器，并正确保存与恢复；第 2) 小问复习双重循环；第 3) 小问用 C 语言实现后察看反汇编并加注释。

## 二、总体结构

程序采用双重循环：

- 外层由 `CX` 保存行号，取值自 9 递减至 1，用 `LOOP` 指令控制；
- 内层由 `BX` 保存列号，取值自 1 递增至当前行号，用 `CMP` 与 `JBE` 控制；
- 每一项输出「行号 * 列号 = 乘积」后输出一个制表符，使各列对齐。

## 三、过程调用与寄存器保护

将「把一个数按十进制输出」这一重复逻辑提取为过程 `PRINT_AX`，入口参数为 `AX`。

该过程内部需要使用四个通用寄存器：`AX` 与 `DX` 用于除法取余，`BX` 存放除数 10，`CX` 记录位数并控制输出循环。而主过程中 `CX` 正保存行号、`BX` 正保存列号，二者存在冲突。

因此 `PRINT_AX` 在入口处依次压栈保存 `AX`、`BX`、`CX`、`DX`，返回前按相反顺序弹栈恢复。顺序必须相反，这是由栈的后进先出特性决定的。

若省略对 `CX` 的保护，除法循环结束时 `CX` 已被减为 0，随之产生三重后果：输出行号与乘积均变为 0；内层循环的 `CMP BX, CX` 条件不再成立，每行仅输出一项即退出；外层 `LOOP` 将 0 减为 `FFFFh`，导致继续空转 65535 次。由此可见过程保护现场的必要性。

保护的代价很小：`PUSH` 与 `POP` 对寄存器有专用编码，每条仅占 1 字节，四条寄存器共 8 字节。

## 四、双重循环的分工

内层循环的上界等于当前行号，是动态量，因此必须与 `CX` 实时比较，不能写成常数。

内层未采用 `LOOP` 指令，原因是 `LOOP` 硬性占用 `CX`，若内层也用则需在进入内层前保存行号、退出后恢复。本题改由 `BX` 计数、以 `CMP` 加条件转移判断，`CX` 全程稳定保存行号，程序结构更为清晰。两种方案并无优劣，区别在于将 `CX` 借出后归还，还是另用寄存器。

## 五、乘法指令

乘积由 `MUL` 求得：

```
MOV  AX, CX        ; AX = 行号
MUL  BX            ; DX:AX = AX × BX
```

16 位乘法的积可能占 32 位，故结果存于 `DX:AX`。本表最大为 9×9=81，`DX` 恒为 0，直接取 `AX` 即可。

## 六、输出对齐

每一项输出完毕后输出 ASCII `09H`（制表符）。DOS 控制台将制表符解释为跳到下一个 8 的整数倍列，而每项均为 5 或 6 个字符，一个制表符即可使各列整齐对齐。

## 七、C 语言实现与反汇编

C 版本用双重 `for` 循环与 `printf("%d*%d=%d\t", row, col, row * col)` 实现，运行结果与汇编版本一致。

`/Od` 反汇编显示：两个 `for` 均被拆为「初始化、条件判断、循环体、步进」四块，跳转关系与手写汇编的 `ROW_LOOP`、`COL_LOOP` 同构；条件一律取反后跳走；局部变量 `row`、`col` 位于栈上（`[ebp-4]`、`[ebp-8]`）。

`/O2` 版本不再建立栈帧，变量提升至寄存器，且出现强度削减：`imul` 被替换为 `add ebx, esi`，即利用「列号每轮加 1、故乘积每轮增加行号」的规律，将乘法改为累加。
