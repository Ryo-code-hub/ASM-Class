# 第一次作业 第 2) 小问：用 `debug -e` 将代码与数据写入内存并执行

## 一、实验目的

第 1) 小问采用传统方式，即由 MASM 汇编、LINK 链接生成 `.EXE` 文件，再由 DOS 装载执行。

本小问不使用上述工具链，改为通过 `debug` 提供的 `-e` 命令，将机器码与字符串逐字节写入内存；再以 `-r` 命令修改段寄存器与指令指针；最后用 `-g` 命令令 CPU 自指定位置开始执行。

两种方式在本质上是相同的：内存中存放一串字节，CPU 自 `CS:IP` 所指位置逐条取指执行。二者的区别仅在于该字节序列是由工具生成并装载，还是由人工逐字节写入。采用后一种方式，可以直接观察内存中的实际内容，有助于理解机器码与程序执行之间的对应关系。

## 二、写入内存的内容

### 2.1 数据：字符串 `Hello$`

字符串 `Hello$` 各字符的 ASCII 码如下表所示。

| 字符 | H | e | l | l | o | $ |
|---|---|---|---|---|---|---|
| ASCII（十六进制） | `48` | `65` | `6C` | `6C` | `6F` | `24` |

```
48 65 6C 6C 6F 24
```

末字节 `24` 即字符 `$`，不可省略。DOS 的 09H 号功能不带长度参数，以 `$` 作为字符串的结束标志；若缺少该字节，输出将越过字符串边界并持续进行。

### 2.2 代码：17 字节机器码

| 字节 | 对应指令 | 作用 |
|---|---|---|
| `B8 6A 07` | `MOV  AX,076A` | AX 置为数据所在段的段地址 |
| `8E D8` | `MOV  DS,AX` | DS 指向数据段 |
| `BA 00 00` | `MOV  DX,0000` | DX 置为字符串在段内的偏移量 |
| `B4 09` | `MOV  AH,09` | 09H 号功能：显示字符串 |
| `CD 21` | `INT  21` | 调用 DOS |
| `B8 00 4C` | `MOV  AX,4C00` | 4CH 号功能：结束程序 |
| `CD 21` | `INT  21` | 调用 DOS |

```
B8 6A 07 8E D8 BA 00 00 B4 09 CD 21 B8 00 4C CD 21
```

字节数合计：`3 + 2 + 3 + 2 + 2 + 3 + 2 = 17`。

## 三、操作步骤

于 DOS 提示符下键入 `debug` 进入调试器，待提示符变为 `-` 后，依次执行以下步骤。

**第 1 步　写入数据**

```dos
-e 076a:0 48 65 6c 6c 6f 24
```

该命令将字符串 `Hello$` 写入 `076A:0000`，此区域用作数据段。

**第 2 步　写入代码**

```dos
-e 076b:0 b8 6a 07 8e d8 ba 00 00 b4 09 cd 21 b8 00 4c cd 21
```

该命令将 17 字节机器码写入 `076B:0000`，此区域用作代码段。

**第 3 步　设置段寄存器与指令指针**

```dos
-r cs
CS 073F
:076b              ← CS 置为 076b（代码所在段）
```

```dos
-r ds
DS 073F
:076a              ← DS 置为 076a（数据所在段）
```

```dos
-r ip
IP 0100
:0                 ← IP 置为 0（自代码段第 0 个字节开始执行）
```

**第 4 步　校验寄存器**

```dos
-r
```

确认 `CS = 076B`、`DS = 076A`、`IP = 0000`，即上述修改均已生效。

**第 5 步　执行**

```dos
-g
```

`-g` 命令令 CPU 自 `076B:0000` 起逐条执行。执行至 4CH 号功能的 `INT 21H` 时程序终止，控制权返回 `debug` 提示符。

## 四、执行结果

屏幕输出为：

```
Hello
```

## 五、地址对应关系

上述段地址 `076A` 与 `076B` 并非任意选定，必须与机器码中直接写入的地址保持一致。

```
机器码第 1 条：B8 6A 07   →   MOV AX,076A
                               ↓
                          执行后 DS = 076A
                               ↓
                   字符串必须存放于 076A 段内

机器码第 3 条：BA 00 00   →   MOV DX,0000
                               ↓
                   即字符串在段内的偏移量为 0
                               ↓
                   故应写入 076A:0000
```

由此可知，机器码中写入的段地址、字符串在段内的偏移量，以及数据的实际存放位置，三者必须相互对应。第 1) 小问中由 DOS 于装载时通过重定位自动完成的工作，在本方式中需由操作者自行保证。

## 六、注意事项

| 序号 | 注意事项 | 说明 |
|---|---|---|
| 1 | 字符串末字节须为 `24`（即 `$`） | 09H 号功能以 `$` 判定字符串结束，缺少该字节将导致输出越界 |
| 2 | `DX` 须等于字符串的实际偏移量 | 字符串写入偏移 0 处时，`DX` 应取 `0000`；若取 `0002`，输出将自第 3 个字符开始 |
| 3 | `CS` 与 `DS` 均须修改 | 前者指定代码所在段，后者指定数据所在段；仅修改其一将无法定位另一部分 |
| 4 | 不可遗漏 `IP` 的修改 | `-g` 自 `CS:IP` 的当前值开始执行；若 `IP` 未修改，执行将不落在所写入的代码上 |
| 5 | 字节数须准确 | 机器码 17 字节，字符串 6 字节 |
| 6 | 应避开正在使用的内存区域 | `076A`、`076B` 等低段地址通常空闲，写入前可先用 `-d 076a:0` 查看原有内容 |
